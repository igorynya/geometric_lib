# Документция по проекту **geometric_lib**.
## Общее описание проекта:
Созданы библиотеки по вычислению площади и периметра различных геометрических фигур:
- rectangle.py - прямоугольник
- triangle.py - треугольника
- square.py - квадрат
- circle.py - окружность

На вход каждой программы подаются переменные, необходимые для вычисления площади или периметра.

## 1. <ins>rectangle.py</ins>
### Функция по вычсислению площади прямоугольника.
На вход получает два числа $a, b$ -  две соседние стороны

Выводит площадь, то есть их произведение: $a * b$

Пример:
        
```Python
import rectangle

print(rectangle.area(10, 15))
```

Результатом выполнения этой программы будет число **150**, выведенное в консоль.
### Функция по вычислению периметра прямоугольника.
На вход получает два числа $a, b$ -  две соседние стороны

Выводит периметр, то есть удвоенное произведение суммы этих сторон: $2 * (a + b)$

Пример:
```Python
import rectangle 

print(rectangle.perimetr(10.1, 12))
```
Результатом выполнения этой программы будет число **44.2**, выведенное в консоль.

## 2. <ins>triangle.py</ins>
### Функция по вычислению площади треугольника.
На вход получает два числа $a, h$ -  основание треугольника и высота, проведенная к этому основанию.

Выводит площадь, то есть их половину произведения : $\dfrac{(a * h)}{2}$

Пример:
        
```Python
import triangle

print(triangle.area(20, 15))
```

Результатом выполнения этой программы будет число **150**, выведенное в консоль.

### Функция по вычислению периметра треугольника.
На вход получает три числа $a, b, c$ - стороны треугольника

Выводит периметр, то есть сумму этих сторон: $a + b + c$

Пример:
```Python
import triangle

print(triangle.perimetr(4, 9, 5))
```
Результатом выполнения этой программы будет число **18**, выведенное в консоль.

## 3. <ins>circle.py</ins>
### Функция по вычислению площади круга.
На вход получает число $r$ - радиус окружности.

Выводит площадь круга, то есть $\pi r^2$

Пример:
```Python
import circle

print(circle.area(10))
```
Результатом выполнения этой программы будет число **314.1592653589793**, выведенное в консоль.

### Функция по вычислению периметра окружности.
На вход получает одно число $r$ - радиус окружности.

Выводит периметр окружности, то есть $2 \pi r$.

Пример:
```Python
import circle

print(circle.perimetr(10))
```
Результатом выполнения этой программы будет число **62.83185307179586**, выведенное в консоль.

## 4. <ins>square.py</ins>
### Функция по вычислению площади квадрата.
На вход получает число $a$ - сторона квадрата.

Выводит площадь квадрата, то есть $a^2$

Пример:
```Python
import square

print(square.area(10))
```
Результатом выполнения этой программы будет число **100**, выведенное в консоль.
### Функция по вычислению периметра квадрата.
На вход получает одно число $a$ - сторона квадрата.

Выводит периметр квадрата, то есть $4a$.

Пример:
```Python
import square

print(square.perimetr(5.2))
```
Результатом выполнения этой программы будет число **20.8**, выведенное в консоль.
